## 2024-05-24 Security Fix\n\n- **Vulnerability**: Hardcoded administrative fallback credentials in source code.\n- **Fix**: Removed default credentials (`matchdistrict.in@gmail.com` and `101010`) and introduced an `APP_ENV === 'production'` check. The server will now crash fast (`process.exit(1)`) with an explicit error message instead of silently defaulting to insecure credentials if `ADMIN_EMAIL` or `ADMIN_PASSWORD` are missing in production.\n- **Prevention**: Never fallback to hardcoded administrative credentials in application code. Rely entirely on secure configuration management and environment variables.
